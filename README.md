# 🚀 Школа - Онлайн школа програмування

Сучасна платформа для навчання програмуванню з нуля до професіонала.

## 📖 Про проект

Повноцінний веб-сайт онлайн-школи програмування з:

- **Головна сторінка** - презентація школи, переваги, курси
- **Сторінка курсів** - детальний опис навчальних програм з фільтрацією
- **Сторінка про нас** - історія, місія, команда
- **Адаптивний дизайн** - коректно відображається на всіх пристроях
- **Інтерактивні елементи** - модальні вікна, анімації

## 🚀 Швидкий старт

### Локальний запуск

1. **Просто відкрийте файл у браузері:**
   ```bash
   # Відкрийте index.html у будь-якому браузері
   ```

2. **Або використайте локальний сервер:**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Потім відкрийте: http://localhost:8000
   ```

### GitHub Pages

1. Перейдіть в Settings → Pages
2. Оберіть гілку `main` та збережіть
3. Ваш сайт буде доступний за: `https://vickordon.github.io/online-school`
